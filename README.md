# Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends in India using Python and a real-world unemployment dataset.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Features
- Monthly unemployment trend analysis
- Region-wise unemployment comparison
- Rural vs Urban unemployment comparison
- Cleaned dataset export
- Analysis summary report

## Dataset
The project uses the `Unemployment in India.csv` dataset.

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

Run the Python script:

```bash
python unemployment_analysis.py
```

## Outputs
- `unemployment_trend.png`
- `unemployment_regional_comparison.png`
- `unemployment_area_comparison.png`
- `cleaned_unemployment_data.csv`
- `analysis_summary.txt`

## Key Findings
- Overall average unemployment rate: 11.79%
- Highest monthly average unemployment rate: 24.88% in May 2020
- Highest-average unemployment region: Tripura
- Average rural unemployment rate: 10.32%
- Average urban unemployment rate: 13.17%

*Results are based on the dataset used in this project.*
